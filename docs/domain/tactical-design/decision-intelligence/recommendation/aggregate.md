# Recommendation Aggregate

A Recommendation is an actionable outcome generated by one Optimization for one
Route.

## Invariants

- It references one Route, Optimization, type, and status.
- Its score and Recommendation facts are valid Domain values.
- Only pending Recommendations may expire or receive analysis.
- Accepted, rejected, and expired state transitions follow the Aggregate's
  conflict rules.

## Behavior

- `accept()`
- `reject()`
- `expire()`
- `attachAnalysis()`

## Domain Events

- `RecommendationCreatedDomainEvent`
- `RecommendationAcceptedDomainEvent`
- `RecommendationRejectedDomainEvent`
- `RecommendationExpiredDomainEvent`
- `RecommendationAnalysisAttachedDomainEvent`

## Owned Concepts

- `RecommendationAnalysis` is a Value Object containing summary, confidence,
  and Findings.
- `Finding` is an Entity categorized as Strength, Risk, or Assumption.
- `RecommendationFact` is a bounded-context Entity describing a measurable
  baseline and recommended value.

## Repository

`RecommendationRepository` exposes `findById`, `findPendingByRouteId`,
`findPending`, `add`, `addMany`, revision-checked `save`, and `delete`. Loaded
Recommendations carry their expected revision for optimistic concurrency.
